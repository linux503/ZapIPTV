# ZapIPTV

亚洲影视与直播应用（macOS / Windows / Android）。

## 官网下载

👉 **https://linux503.github.io/ZapIPTV/**

- **macOS**：Universal DMG（Apple Silicon + Intel）
- **Windows**：便携 EXE
- **Android**：APK（手机 / 电视盒子）

## App 功能一览

侧栏与官网说明一致：

| 分区 | 说明 |
|------|------|
| 首页 | 继续观看、直播 / 体育 / 点播快捷入口 |
| 直播 | 亚洲分区目录浏览；大陆频道按 IP 智能选线 |
| 体育 | 独立卡片目录（足球 / 篮球 / 综合等） |
| 电影 | 真点播，可拖进度 |
| 剧集 | 分集连看，可拖进度 |
| 收藏 | 常看频道一键打开 |
