FAQ

How to install on macOS?

Open the DMG, then drag ZapIPTV.app into the Applications folder. After that, launch it from Launchpad or Finder.

Is IPTV/M3U the main focus?

No. IPTV/M3U import is an integrated capability. ZapIPTV’s core value is a curated, region-first experience for movies, Asian dramas, anime, and live channels.

Why does the first run take time?

On first launch, sources are seeded and channels are loaded in the background. You can keep exploring while loading completes.

Windows roadmap?

Windows client will reuse the same catalog concepts first (CN/TW/HK/JP/KR/SEA), then connect playback through VLC for IPTV streams.
