说明

Windows / Android 什么时候能下？

官网已经按三端预留入口。安装包会先发到 GitHub Releases，再把本页按钮换成直链。请 Watch 仓库或看 Releases。

Mac 第一次打不开？

ad-hoc 签名。右键 App → 打开，或到隐私与安全性点仍要打开。

三个系统源一不一样？

目录规划一致：亚洲优先，默认中国大陆。各端播放器用系统或 VLC，体验会略有差别。
