說明

Android 提示無法安裝？

到系統設定允許「未知來源」或「安裝未知應用」，再重新安裝 APK。

Mac 提示無法打開？

右鍵 App 選打開，或到系統設定 → 隱私與安全性 → 仍要打開。

三個系統內容一樣嗎？

目錄規劃一致：亞洲優先，預設中國大陸，並有獨立體育。播放器按系統會略有差別。

體育在哪裡？

Mac 版側欄有獨立「體育」；可按足球、籃球、綜合台等分類瀏覽。Android / Windows 同樣收錄體育頻道。

為什麼有時顯示線路切換中？

同一個頻道可能有多條備用線路。當前線路連不上時，會自動換下一條，稍等即可。

電影能拖進度，直播為什麼沒有？

直播與體育是即時流，不顯示進度條；電影與劇集是點播，可拖動、快進快退。

電影和劇集跟直播頻道一樣嗎？

不一樣。直播／體育是頻道流；電影／劇集是獨立點播庫，不會把直播頻道塞進影視頁。

國內和外網看大陸台有什麼差別？

App 會偵測 IP：國內優先低延遲線路並競速；國際 IP 優先海外友好源。播不了仍會自動切備用線路。
