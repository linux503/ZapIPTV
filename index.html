说明

Windows / Android 什么时候能下？

会先放到 GitHub Releases，再把本页改成直链。可 Watch 仓库。

Mac 提示无法打开？

右键 App 选打开，或到系统设置 → 隐私与安全性 → 仍要打开。

三个系统内容一样吗？

目录规划一致：亚洲优先，默认中国大陆。播放器按系统会略有差别。
