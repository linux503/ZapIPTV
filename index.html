1.1.8 更新了什么

新 Logo、国内直播源，以及华语电影/电视剧频道。

国内直播

新增国内 IPv4 直播列表（央视 / 卫视 / 地方台），和原有中国源一起用，能打开的更多。

华语影视

加入 CCTV-6 电影、CCTV-8 电视剧、CHC 及剧场等线性影视频道，Home 和 Movies 都能看到。

新 Logo

应用图标换成闪电 Z，macOS Dock 和官网同步更新。

核心功能

亚洲直播

按地区整理频道，点击即播。国内另有央视卫视地方台列表，坏链会自动跳过。

华语影视

电影频道、电视剧频道走线性直播（CCTV6/8、CHC、剧场）。完整片库请用你自己的 M3U / Xtream。

自加源

可以自己加播放列表。内置的 iptv-org 全球源会被过滤，自定义中文源会保留。

覆盖地区

第一期只做高信号的亚洲市场。

安装步骤

  1. 下载 DMG，双击打开。
  2. 把 ZapIPTV.app 拖进 应用程序。
  3. 第一次打开：若提示无法验证开发者，到「系统设置 → 隐私与安全性」点仍要打开，或右键 App 选打开。
  4. 等几秒加载源。Live TV 应出现 🇨🇳 中国大陆。

覆盖安装即可。1.1.8 会自动清理旧英文源，不用手动 Reset。
