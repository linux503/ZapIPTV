三個系統

同一套亞洲目錄

直播、體育、影視與春晚都在一個 App 裡，Mac / Windows / Android 目錄一致。

直播

第一屏就是中國大陸。央視、衛視、地方台。CCTV 同名頻道合併成一條，多線路自動切換。

體育

獨立體育選單：足球、籃球、綜合台、美職等分區整理。NBA TV、國內體育與全球賽事台都在這裡。

影視

電影、劇集分頁更清晰。CCTV-6、CHC、華語輪播，還有歷年春晚。

備用線路

播不了會提示「線路切換中」，自動試下一條備用源，少卡在連接中。

多語言

App 和官網支援繁體、簡體與英文，下拉一鍵切換。

一個視窗

點了就在主視窗裡播，不另開播放器。也可匯入自己的 M3U / Xtream。

說明

Android 提示無法安裝？

到系統設定允許「未知來源」或「安裝未知應用」，再重新安裝 APK。

Mac 提示無法打開？

右鍵 App 選打開，或到系統設定 → 隱私與安全性 → 仍要打開。

三個系統內容一樣嗎？

目錄規劃一致：亞洲優先，預設中國大陸，並有獨立體育。播放器按系統會略有差別。

體育在哪裡？

Mac 版側欄有獨立「體育」；可按足球、籃球、綜合台等分類瀏覽。Android / Windows 同樣收錄體育頻道。

為什麼有時顯示線路切換中？

同一個頻道可能有多條備用線路。當前線路連不上時，會自動換下一條，稍等即可。
